# Zerocoder Reviews — сбор и аналитика отзывов из открытых источников

## Проблема

Отзывы об университете Zerocoder разбросаны по десятку площадок: Отзовик, Яндекс Карты, 2ГИС, Google Maps, TutorTop, iRecommend, KursHub, okursah, skill2go, pgdv. Чтобы понять реальную картину репутации — что хвалят, на что жалуются, какие курсы проседают — нужно вручную обойти каждый сайт, скопировать тексты, разложить по таблицам и свести в одну картину. На это уходят дни, и через месяц всё устаревает.

Этот проект автоматизирует весь цикл: сбор → нормализация → аналитика → готовый дашборд.

## Для кого

- **Руководитель клиентского сервиса** — видит репутацию университета в одной точке, понимает, какие курсы требуют внимания, какие площадки нужно мониторить.
- **Отдел маркетинга** — получает реальные цитаты студентов «зашло / не зашло» для лендингов и рекламы.
- **Отдел продаж** — узнаёт причины выбора курса и типичные возражения «до покупки».
- **Команда поддержки** — видит список неотвеченных отзывов с предложенными вариантами ответа.

## Основная функция

| Этап | Что подаётся на вход | Что получается на выходе | Инструменты |
|------|---------------------|--------------------------|-------------|
| **1. Парсинг площадок** | URL площадки | `data/WebReviews/reviews-{площадка}.{csv,json}` со схемой `date, name, rating, title, text, pros, cons, reply, url, source_page` | `scripts/parse-*.py` (`requests` + `BeautifulSoup` для статики, Playwright для SPA, интерактивные парсеры с обходом капчи для Отзовика и iRecommend) |
| **2. Нормализация** | Все `reviews-*.csv` + внутренние выгрузки GetCourse | Единый `data/unified-reviews.csv` | `scripts/normalize-reviews.py` + подагент `review-normalizer` |
| **3. Аналитика** | `unified-reviews.csv` | `tmp/dashboard-data.json` — средние рейтинги по курсам и площадкам, динамика по месяцам, темы (контент, кураторы, платформа, цена, поддержка) | `scripts/analyze-reviews.py` + подагент `review-analyst` |
| **4. Инсайты** | `dashboard-data.json` + сырые отзывы | `reports/{date}-sales-insights.md` — цитаты для продаж и маркетинга | Подагент `insights-extractor` |
| **5. Дашборд** | `dashboard-data.json` + блок insights | `reports/{date}-reviews-dashboard.html` (тёмная тема, Chart.js) + плоские `reports/sheets/*.csv` для Google Sheets | `scripts/build-reviews-dashboard.py` + подагент `dashboard-builder` |
| **6. Неотвеченные** | `unified-reviews.csv` за последние 6 месяцев | `reports/{date}-unanswered-reviews.{md,csv}` с предложенным ответом для каждого | `scripts/draft-unanswered.py` + подагент `response-drafter` |
| **7. Мониторинг** | `monitor-config.json` + baseline | Email-уведомление при появлении новых отзывов | `scripts/monitor.py` |

Вся цепочка оркестрируется одной командой через слэш-скилл `/reviews-refresh`.

## Формат результата

- **HTML-дашборд** — тёмная тема (#1C1C1C), Chart.js 4.4.0, корпоративные акценты Zerocoder (зелёный/фиолетовый/жёлтый). Содержит: средний рейтинг, распределение оценок, динамика по месяцам, топ слабых/сильных курсов, разбор тем. Пример выложен в репозитории: [`reports/2026-06-11-reviews-dashboard.html`](reports/2026-06-11-reviews-dashboard.html).
- **CSV-таблицы** для импорта в Google Sheets (`reports/sheets/`).
- **Markdown-отчёты** — sales-insights, growth-plan, разбор негативных отзывов по конкретному курсу, лист неотвеченных отзывов.

## MVP (что уже работает)

- Парсеры под 9 из 11 согласованных площадок: Отзовик, TutorTop, okursah, skill2go, KursHub, 2ГИС, pgdv, Яндекс Карты, iRecommend. Итого собрано **~1780 отзывов** (из них 315 уже с ответом представителя). Google Maps обновляется вручную, по 2ГИС используется fallback через MCP Playwright.
- Единая схема `unified-reviews.csv` для всех источников.
- HTML-дашборд + CSV-выгрузка для Google Sheets.
- Sales-insights с цитатами под лендинги.
- Отчёт по неотвеченным отзывам за последние 6 месяцев + предложенный ответ.
- Скрипт мониторинга с уведомлением на email при появлении новых отзывов.

### Что в планах

- Подагент `review-parser` — оркестратор всех парсеров под единый запуск.
- Покрытие оставшихся площадок без отдельного парсера.
- Автоматический ежемесячный прогон по cron-расписанию.

## Технологии

- **Язык:** Python 3.11
- **Парсинг:**
  - `requests` + `beautifulsoup4` — для статичных страниц (TutorTop, KursHub, pgdv).
  - `playwright` (Chromium, headless) — для SPA (okursah, skill2go, Яндекс Карты).
  - Интерактивные сессии с сохранением cookies (`storage_state`) — для площадок с капчей (Отзовик, iRecommend).
- **Данные:** CSV + JSON (для каждого парсера сохраняется обе версии — CSV для Excel/Sheets, JSON для скриптов).
- **Аналитика:** стандартный `csv` (вместо pandas — из-за неэкранированных кавычек в исходных CSV GetCourse), агрегаты в `dict`, сериализация в JSON.
- **Визуализация:** статический HTML + [Chart.js 4.4.0](https://www.chartjs.org/) через CDN, без бэкенда и сборщиков.
- **Оркестрация:** подагенты Claude Code в `.claude/agents/` (`review-normalizer`, `review-analyst`, `insights-extractor`, `dashboard-builder`, `response-drafter`) и слэш-скиллы (`/reviews-refresh`, `/reviews-unanswered`, `/reviews-parse-otzovik`).
