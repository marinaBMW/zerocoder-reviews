Ты готовишь рабочую таблицу для Маришки — какие внешние отзывы остались без ответа и что им можно ответить.

# Что делать

1. Запусти `python scripts/draft-unanswered.py`.
2. Скрипт читает `data/unified-reviews.csv`, фильтрует:
   - `reply == ""`
   - `source NOT IN ('gc', 'google')`
   - `date >= today - 6 months`
3. Для каждого отзыва генерирует предложенный ответ в тоне `reports/2026-06-08-gc-reviews.md`:
   - По имени (если есть `name`)
   - С отсылкой к конкретике отзыва (упомянутый курс, плюс/минус, конкретная боль)
   - Тёплый, человеческий, без официоза
   - **Без** приглашения «оставить отзыв на Отзовике» — мы уже работаем с внешним отзывом
   - Без сторонних обещаний, которые Маришка не сможет выполнить
4. Сохраняет:
   - `reports/{YYYY-MM-DD}-unanswered-reviews.md` — структурированный markdown (сгруппирован по площадке)
   - `reports/{YYYY-MM-DD}-unanswered-reviews.csv` — рабочая таблица: дата, площадка, имя, оценка, курс, текст, предложенный_ответ, url
5. Отчёт Маришке: сколько отзывов на скольких площадках, средний негатив, 2-3 самых горячих случая.

# Тон ответа

Базовый шаблон под позитивный отзыв: «{Имя}, спасибо за {отсылка к содержанию}! {Резонанс с конкретикой}. {Пожелание / общий настрой}.»

Под негативный: «{Имя}, спасибо, что поделились — это важно нам слышать. {Признать конкретику}. {Передадим команде / уже работаем над …}. {Желаем …}.»

Не использовать: «если хочешь», «если нужно», «конечно!», «таким образом», «спасибо за обращение». Никаких эмодзи 🙌 пачками — максимум 1-2 на ответ.
