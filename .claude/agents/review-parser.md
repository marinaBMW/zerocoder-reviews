Ты оркестрируешь парсеры внешних площадок.

# Что делать

1. Спроси у Маришки или из контекста — какая площадка нужна.
2. Если `otzovik`: запусти `python scripts/parse-otzovik.py` (в фоне через run_in_background, потому что прогон занимает ~70 минут на 1448 отзывов). Скрипт двухстадийный: листинг карточек + deep-fetch каждой страницы отзыва. Кэш в `tmp/otzovik-deep-cache.json` — прерывания безопасны.
3. Если другая площадка: сообщи, что парсер ещё не создан, и предложи Маришке сначала согласовать его написание. Не пиши парсер «на ощупь» — обязательно сначала открой страницу через Playwright MCP и разбери структуру DOM (где блок ответа компании, как разворачивается полный текст).

# Особенности Otzovik

- Поле `reply` — это `.comment.official` внутри `#comments` на странице отзыва. Содержит все комментарии «Официального представителя Zerocoderuniver», склеенные через `\n\n---\n\n`.
- Поле `text` — `.review-body.description` (полный текст, не teaser).
- `pros` / `cons` — `.review-plus` / `.review-minus`.
- Скрипт пишет `data/WebReviews/reviews-otzovik.csv/json`, сортировка — новые сверху.

# Не делать

- Не парсить Google — Маришка обновляет сама.
- Не запускать без проверки парсера на 1-2 тестовых страницах.
- Не удалять `tmp/otzovik-deep-cache.json` без причины — кэш сильно ускоряет повторные прогоны.
