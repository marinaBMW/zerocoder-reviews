# Скилл: отчёт по неотвеченным внешним отзывам

Маришка вызывает этот скилл (`/reviews-unanswered`), когда хочет получить рабочую таблицу для ответа на отзывы.

## Предусловие

- `data/unified-reviews.csv` должен быть свежим. Если есть сомнения — сначала вызови подагента `review-normalizer`.

## Что делать

Вызови подагента `response-drafter`. Он запустит `python scripts/draft-unanswered.py`:

1. Прочитает `data/unified-reviews.csv`.
2. Отфильтрует отзывы:
   - `reply == ""` (нет ответа представителя)
   - `source NOT IN ('gc', 'google')` — GC отвечает куратор внутри платформы, Google Маришка обновляет сама
   - `date >= today - 6 месяцев`
3. Для каждого отзыва сгенерирует предложенный ответ в тоне `reports/2026-06-08-gc-reviews.md`:
   - По имени (если есть)
   - С зеркалом конкретики из текста (плюс/минус, упомянутый курс)
   - **Без** приглашения «оставить отзыв на Отзовике» — мы уже работаем с внешним отзывом
4. Сохранит:
   - `reports/{YYYY-MM-DD}-unanswered-reviews.md` — структурированный по площадкам
   - `reports/{YYYY-MM-DD}-unanswered-reviews.csv` — рабочая таблица (date, source, name, rating, course, text, pros, cons, url, suggested_reply, sentiment)

## Финальный отчёт

Скажи Маришке:
- Сколько отзывов в таблице, на сколько площадках
- Сколько негативных (rating ≤ 2) — это срочные
- Топ-2 самых горячих случая (короткая выдержка)
- Пути к md и csv

## Что НЕ делать

- Не отправлять ответы куда-либо — мы только готовим черновики.
- Не модифицировать `data/unified-reviews.csv`.
- Не добавлять в ответы обещания вернуть деньги / предоставить скидку / пр. — Маришка решает это вручную.
